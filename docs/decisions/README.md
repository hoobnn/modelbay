# 架构决策记录（ADR）

## 规则

- ADR 只记录不可逆或代价高的取舍。普通的实现选型和操作步骤写进其他文档。
- 允许重写，正文只保留现行决策。被取代的直接删除，不保留「已取代」状态。
- 状态只有「提议」和「已接受」两种。
- 文件名格式为 `NNNN-短横线标题.md`，编号不复用。
- 正文包括背景、决策、理由、代价与约束；需要时加未决事项。
